# Alisa Finds – Privacy Policy

**Last updated: October 30, 2026**

Alisa Finds respects your privacy.

## Information we access

Our Pinterest automation application accesses the Pinterest account information necessary to manage our own business account, including Pinterest board information and authorization tokens.

## How we use information

We use Pinterest API access exclusively to:
- Retrieve our Pinterest boards.
- Schedule and publish Pins.
- Manage publishing activity for Alisa Finds.

## Data storage and security

Pinterest authorization credentials are stored securely in Google Apps Script Properties. Product information and publishing schedules are maintained in Google Sheets.

We do not sell, rent or share Pinterest account credentials with third parties.

## Third-party services

Our application uses Pinterest API and Google Apps Script services. Their respective privacy policies and terms apply.

## Data retention and deletion

We retain information only as necessary to operate the application. Users can revoke Pinterest access through their Pinterest account settings. Stored application credentials can be deleted from Google Apps Script project properties.
